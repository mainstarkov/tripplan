# TripPlan

Локальный планировщик путешествий. Помогает собрать маршрут, расходы и список вещей в одном месте.

[Открыть демо](https://mainstarkov.github.io/tripplan/)

## Возможности

- Позволяет создать поездку и добавлять места в маршрут.
- Показывает план и фактические расходы в разделе бюджета.
- Сохраняет поездки и список вещей в `localStorage` браузера.

## Скачать и запустить

**Требования.** Современный браузер. Для локального HTTP-сервера понадобится Python 3.

Скачайте [ZIP исходников](https://github.com/mainstarkov/tripplan/archive/refs/heads/main.zip) и откройте папку `tripplan-main` **или** клонируйте репозиторий:

```sh
git clone https://github.com/mainstarkov/tripplan.git
cd tripplan
```

Выполните в этой папке:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

В Windows PowerShell замените `python3` на `py -3`, если используете стандартный установщик Python.

Откройте http://127.0.0.1:8000. Сервер можно остановить через Ctrl+C.

## Проверить работу

Создайте поездку, добавьте место и расход, отметьте вещь в списке и обновите страницу. Записи должны остаться в том же браузере и на том же адресе.

## Как устроено

`index.html` задаёт интерфейс, `js/app.js` управляет данными, `css/style.css` отвечает за оформление.
